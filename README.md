# Практическая работа 1 — Эмулятор командной оболочки ОС

**Дисциплина:** Конфигурационное управление · **Вариант 15**

Разработка эмулятора для языка оболочки ОС. Цель — сделать работу эмулятора
максимально похожей на работу в командной строке UNIX-подобной ОС.

Работа выполняется в пять этапов, каждый этап завершается стандартно
оформленным коммитом (Conventional Commits).

## Структура проекта

```
Практика 1/
├── README.md
├── .gitignore
├── config.example.toml    # пример конфигурации (этап 2)
├── run.bat / run.sh       # запуск эмулятора
├── src/
│   ├── emulator.py        # GUI-эмулятор (REPL, конфигурация, скрипты)
│   ├── config.py          # параметры CLI + TOML-конфиг
│   └── parser.py          # парсер командной строки (кавычки)
├── scripts/
│   ├── demo_ok.esh        # стартовый скрипт эмулятора (успешный)
│   ├── demo_err.esh       # стартовый скрипт с ошибкой (останов)
│   ├── run_demo.bat       # демонстрация CLI-параметров (Windows)
│   └── run_demo.sh        # демонстрация CLI-параметров (Linux/macOS)
└── tests/
    ├── test_parser.py
    └── test_config.py
```

## Запуск

Требуется Python 3.11+ (модули `tkinter` и `tomllib` входят в стандартную
поставку).

```bat
run.bat
```

```bash
./run.sh
```

### Параметры командной строки (этап 2)

| Параметр | Назначение |
|----------|------------|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту эмулятора |
| `--config PATH` | путь к конфигурационному файлу (TOML) |

Примеры:

```bat
run.bat --vfs vfs\example.csv --script scripts\demo_ok.esh
run.bat --config config.example.toml
```

Демонстрация всех параметров сразу: `scripts\run_demo.bat`
(каждый вызов открывает окно эмулятора — закройте его, чтобы продолжить).

### Конфигурационный файл (TOML)

Значения из файла **имеют приоритет** над значениями командной строки.

```toml
vfs = "vfs/example.csv"
script = "scripts/demo_ok.esh"
```

## Этап 1. REPL (реализовано)

| # | Требование | Где |
|---|------------|-----|
| 1 | GUI | `emulator.py` (tkinter) |
| 2 | Имя VFS в заголовке окна | `ShellEmulator.__init__` |
| 3 | Парсер аргументов в кавычках | `parser.py` (`shlex`) |
| 4 | Ошибки (неизвестная команда, неверные аргументы) | `execute`, `cmd_cd` |
| 5 | Заглушки `ls`, `cd` | `cmd_ls`, `cmd_cd` |
| 6 | Команда `exit` | `cmd_exit` |
| 7 | Интерактивный режим | окно + обработка ошибок |
| 8 | Коммит | `feat:` этап 1 |

## Этап 2. Конфигурация (реализовано)

| # | Требование | Где |
|---|------------|-----|
| 1 | CLI-параметры `--vfs`, `--script`, `--config` | `config.parse_args` |
| 2 | Конфиг в формате TOML (vfs, script) | `config.load_config` |
| 3 | Чтение параметров из CLI и файла | `config.build_config` |
| 4 | Приоритет файла над командной строкой | `config.build_config` |
| 5 | Ошибка чтения конфигурации | `_print_startup` |
| 6 | Стартовый скрипт, останов при первой ошибке | `run_script` |
| 7 | Ошибка исполнения скрипта | `run_script`, `execute` |
| 8 | Команда `conf-dump` (ключ-значение) | `cmd_conf_dump` |
| 9 | Скрипты ОС для проверки параметров | `scripts/run_demo.*` |
| 10 | Коммит | `feat:` этап 2 |

Отладочный вывод всех параметров выполняется при запуске (метод
`_print_startup`).
