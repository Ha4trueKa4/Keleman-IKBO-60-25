# Практическая работа 1 — Эмулятор командной оболочки ОС

**Дисциплина:** Конфигурационное управление · **Вариант 15**

Разработка эмулятора для языка оболочки ОС. Цель — сделать работу эмулятора
максимально похожей на работу в командной строке UNIX-подобной ОС.

Работа выполняется в пять этапов, каждый этап завершается стандартно
оформленным коммитом (Conventional Commits).

## Структура проекта

```
Практика 1/
├── README.md          # этот файл
├── .gitignore
├── run.bat            # запуск под Windows
├── run.sh             # запуск под Linux/macOS
├── src/
│   ├── emulator.py    # GUI-эмулятор (REPL)
│   └── parser.py      # парсер командной строки (кавычки)
└── tests/
    └── test_parser.py # тесты парсера
```

## Запуск

Требуется Python 3 (модуль `tkinter` входит в стандартную поставку).

```bat
run.bat
```

```bash
./run.sh
```

Можно задать имя VFS аргументом: `run.bat myvfs` (или через переменную
окружения `VFS_NAME`). Имя VFS отображается в заголовке окна.

## Тесты

```bash
python -m unittest discover -s tests
```

## Этап 1. REPL (реализовано)

Минимальный прототип. Большинство функций — заглушки, но диалог с
пользователем уже поддерживается.

| # | Требование | Где реализовано |
|---|------------|-----------------|
| 1 | Графический интерфейс (GUI) | `src/emulator.py` — tkinter |
| 2 | Заголовок окна содержит имя VFS | `self.root.title(...)` |
| 3 | Парсер аргументов в кавычках | `src/parser.py` (`shlex`) |
| 4 | Ошибки выполнения (неизвестная команда, неверные аргументы) | `execute`, `cmd_cd` |
| 5 | Команды-заглушки `ls`, `cd` (печатают имя и аргументы) | `cmd_ls`, `cmd_cd` |
| 6 | Команда `exit` | `cmd_exit` |
| 7 | Демонстрация в интерактивном режиме | см. «Примеры» ниже |
| 8 | Результат — отдельный коммит | этап = коммит |

### Примеры работы

```
vfs$ ls
ls []
vfs$ ls -l "my dir"
ls ['-l', 'my dir']
vfs$ cd /home
cd ['/home']
vfs$ cd a b
cd: слишком много аргументов
vfs$ foobar
foobar: команда не найдена
vfs$ ls "oops
ошибка разбора: No closing quotation
vfs$ exit
```

## Дальнейшие этапы (вариант 15)

- **Этап 2. Конфигурация** — параметры запуска (путь к VFS, стартовый
  скрипт), вывод конфигурации, выполнение стартового скрипта.
- **Этап 3. VFS** — виртуальная файловая система в памяти, загрузка из
  архива, команда информации о VFS.
- **Этап 4. Команды** — реальная реализация `ls`/`cd` и дополнительных
  команд.
- **Этап 5. Доп. команды** — работа с файлами VFS.
