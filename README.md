# Конфигурационное управление — практические работы

**Группа:** ИКБО-60-25 · **Вариант:** 15

| Папка | Работа | Описание |
|-------|--------|----------|
| [prac1](prac1/) | Практическая работа 1 | Эмулятор командной оболочки ОС с виртуальной файловой системой (VFS из CSV) |
| [prac2](prac2/) | Практическая работа 2 | Визуализатор графа зависимостей пакетов apt: BFS с рекурсией, PlantUML |

Каждая работа — самостоятельный проект со своими `README.md`,
`.gitignore`, папками `src` и `tests` и скриптами запуска. Этапы каждой
работы отражены в истории коммитов (Conventional Commits). Подробное
описание, команды и примеры — в README соответствующей папки.

## Быстрый старт

Требуется Python 3.11+, сторонние зависимости не нужны.

Практическая работа 1:

```bash
cd prac1
./run.sh
python -m unittest discover -s tests
```

Практическая работа 2:

```bash
cd prac2
./run.sh
python -m unittest discover -v
```

В Windows вместо `./run.sh` используется `run.bat`.
