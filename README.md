# Практическая работа 1 — Эмулятор командной оболочки ОС

**Дисциплина:** Конфигурационное управление · **Вариант 15**

Разработка эмулятора для языка оболочки ОС. Цель — сделать работу эмулятора
максимально похожей на работу в командной строке UNIX-подобной ОС.

Работа выполняется в пять этапов, каждый этап завершается стандартно
оформленным коммитом (Conventional Commits).

## Запуск

Требуется Python 3.11+ (модули `tkinter` и `tomllib` входят в стандартную
поставку).

```bat
run.bat
```

```bash
./run.sh
```

### Параметры командной строки (этап 2)

| Параметр | Назначение |
|----------|------------|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту эмулятора |
| `--config PATH` | путь к конфигурационному файлу (TOML) |

Примеры:

```bat
run.bat --vfs vfs\example.csv --script scripts\demo_ok.esh
run.bat --config config.example.toml
```

Демонстрация всех параметров сразу: `scripts\run_demo.bat`
(каждый вызов открывает окно эмулятора — закройте его, чтобы продолжить).

### Конфигурационный файл (TOML)

Значения из файла **имеют приоритет** над значениями командной строки.

```toml
vfs = "vfs/example.csv"
script = "scripts/demo_ok.esh"
```

### Формат VFS (CSV)

Каждая строка — узел VFS. Колонки:

| Колонка | Значение |
|---------|----------|
| `path` | полный путь, например `/home/user/file.txt` (вложенность — через `/`) |
| `type` | `dir` или `file` |
| `content` | для файлов — содержимое в **base64**; для каталогов — пусто |

VFS целиком загружается в память (дерево `VfsNode`); исходный CSV не
изменяется. При запуске выводится сводка: число файлов, каталогов и
максимальная глубина.

```bat
run.bat --vfs vfs\multi.csv
run.bat --vfs vfs\multi.csv --script scripts\stage3_all.esh
```

## Этап 4. Основные команды (реализовано)

| # | Требование | Где |
|---|------------|-----|
| 1 | Реальная логика `ls` и `cd` по дереву VFS | `cmd_ls`, `cmd_cd` |
| 2 | Новые команды `uptime`, `find`, `tree` | `cmd_uptime`, `cmd_find`, `cmd_tree` |
| 3 | Стартовый скрипт со всеми командами и ошибками | `scripts/stage4_all.esh` |
| 4 | Коммит | `feat:` этап 4 |

Команды работают с загруженной VFS; приглашение показывает текущий
каталог, например `multi.csv:/home/user$`.

| Команда | Что делает |
|---------|-----------|
| `ls [путь]` | содержимое каталога (по умолчанию — текущего) |
| `cd [путь]` | сменить каталог (абсолютный/относительный, `..`, `/`) |
| `tree [путь]` | дерево каталога с отступами |
| `find [путь]` | все пути внутри каталога (рекурсивно) |
| `uptime` | время работы эмулятора |

```bat
run.bat --vfs vfs\multi.csv --script scripts\stage4_all.esh
```

## Этап 5. Дополнительные команды (реализовано)

| # | Требование | Где |
|---|------------|-----|
| 1 | Команды `mkdir` и `rm` | `cmd_mkdir`, `cmd_rm`, `vfs.make_dir`, `vfs.remove` |
| 2 | Стартовый скрипт со всеми командами и ошибками | `scripts/stage5_all.esh` |
| 3 | Коммит | `feat:` этап 5 |

| Команда | Что делает |
|---------|-----------|
| `mkdir путь` | создать каталог |
| `rm путь` | удалить файл или каталог |

**Изменения вносятся только в память** — дерево VFS меняется, а исходный
CSV-файл не модифицируется.

```bat
run.bat --vfs vfs\multi.csv --script scripts\stage5_all.esh
```
