# Практическая работа 2 — Визуализатор графа зависимостей

**Дисциплина:** Конфигурационное управление · **Вариант 15**

Инструмент визуализации графа зависимостей для менеджера пакетов
**apt (Ubuntu)**. Готовые менеджеры пакетов и сторонние библиотеки для
получения зависимостей не используются — формат репозитория
разбирается самостоятельно. Текстовая визуализация графа строится на
языке диаграмм **PlantUML**.

Работа выполняется в пять этапов, каждый этап завершается стандартно
оформленным коммитом (Conventional Commits).

## Структура проекта

```
Практика 2/
├── README.md
├── .gitignore
├── config.example.ini     # пример конфигурации (INI)
├── run.bat / run.sh        # запуск анализатора
├── src/
│   ├── main.py             # CLI: чтение конфигурации и вывод
│   └── config.py           # параметры из INI + валидация
├── examples/               # примеры конфигураций с ошибками
├── repos/                  # тестовые репозитории (этап 3)
├── scripts/                # демонстрационные скрипты ОС
└── tests/
    └── test_config.py
```

## Запуск

Требуется Python 3.11+ (используется только стандартная библиотека:
`configparser`, `argparse`, `urllib`, `gzip`).

```bat
run.bat
```

```bash
./run.sh
```

По умолчанию берётся `config.example.ini`. Можно указать свой конфиг:

```bat
run.bat --config config.example.ini
```

## Тесты

```bash
python -m unittest discover -s tests
```

## Этап 1. Минимальный прототип с конфигурацией (реализовано)

Единственный источник параметров — конфигурационный файл формата
**INI** (секция `[analyzer]`).

| Параметр | Назначение |
|----------|------------|
| `package` | имя анализируемого пакета |
| `repo_url` | URL репозитория apt или путь к тестовому репозиторию |
| `test_mode` | режим работы с тестовым репозиторием (true/false) |
| `version` | версия пакета (пусто — любая) |
| `ascii_tree` | выводить зависимости в виде ASCII-дерева (true/false) |
| `max_depth` | максимальная глубина анализа |
| `filter` | подстрока для исключения пакетов (пусто — без фильтра) |

| # | Требование | Где |
|---|------------|-----|
| 1 | Параметры из INI-файла | `config.load_config` |
| 2 | Все семь настраиваемых параметров | `config.Config` |
| 3 | Вывод параметров «ключ-значение» при запуске | `main.format_params` |
| 4 | Обработка ошибок всех параметров | `config` + `scripts/demo_stage1.*` |
| 5 | Коммит | `feat:` этап 1 |

Демонстрация обработки ошибок (отсутствие параметра, неверное число,
неверное булево значение):

```bash
./scripts/demo_stage1.sh
```
